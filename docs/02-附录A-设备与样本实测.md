## A.7 帧缓冲（关键）

活动 DTS /reserved-memory/mblock-18-framebuffer：

    mblock-18-framebuffer {
        reg = <0x00 0x76720000 0x00 0x27e0000>;
        compatible = "mediatek,framebuffer";
    };

推算：0x27E0000 = 41,811,968 B；1088 x 2400 x 4 = 10,444,800 B -> 正好 4 个缓冲。
第一缓冲：**base 0x76720000，宽 1080，高 2400，stride 1088x4 = 4352，格式 a8r8g8b8。**

## A.10 fastboot 能力探测（结论性）

    fastboot getvar product
    product: k6833v1_64
    fastboot getvar unlocked
    unlocked: yes
    fastboot oem help
    FAILED (remote: 'unknown command')

    fastboot boot backup/boot.img
    Sending 'boot.img' (32768 KB)                      OKAY [  0.806s]
    Booting                                            FAILED (usb_read failed with status e00002ed)

    # 机器自动复位回 Android
    adb shell getprop ro.boot.bootreason

**结论：LK 的 cmd_boot 不可用。只能 fastboot flash boot。**
