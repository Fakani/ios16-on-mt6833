# v80：真实触摸报告格式确认

接续[v78固件运行](07-IRAM固件加载与活体握手打通.md)。

[v79照片](../../logs/v79-user-photo.jpg)保存了mask为0的未知/空响应，不能直接用作协议模板。v80保持线速、固件和轮询间隔，只保存已知报告头且负和校验有效的包。

## v80实机证据

[原始照片副本](../../logs/v80-user-photo.jpg)：FW phase/error=0x70000，reads/samples=0x970003，RP status=0x7f，valid43/72=0x20，last ACK/ID=0xa35b，三份mask均0x5。

结论：32个有效72字节包、0个有效43字节包；报告ID=0x5B；所有72字节sum%256=0。每指从4+5*i开始，X/Y各16位大端，第5字节为压力/面积；坐标四字节全FF表示不存在。

v80最大坐标4001/9423；v79有效统计曾到4223/9599，与本机DT的4320×9600范围相符。内部TP信息2047不用于像素报告缩放。

[照片A精确fixture](../tests/v80-real-packet-a.json)已独立转录并验算sum=0，finger0为231/321，归一化65535坐标为3505/2191。B有字形歧义，没有猜测补成精确fixture。

## 实现与边界

[采集器](../include/touch-report-capture.c)为15秒只读报告窗口，保存前两个有效不同样本及最新样本；IRQ14复用/方向/IES均保存恢复。位采样、CRC与IRQ恢复由[host peer](../tests/ilitek_report_peer.c)验证，另保留实机照片。采集阶段没有向桌面发HID。

v80镜像SHA256：05f055648c89dbeb0c96ccf9e5a95106c266591f666e98fb1b6d0975e0c0e00a。

新HID线程须保留loader已启动固件，跳过RESET15/旧host-download；使用0x5B/72字节/负和、slave offset3、16位坐标及每指状态。旧32字节读/43字节校验/正和和全局last_x/y不再沿用。
