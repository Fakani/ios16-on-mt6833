接续[v76 GPIO身份打通](05-GPIO触摸身份打通.md)。本阶段没有下载AP固件，仅核对文件并验证厂商dummy寄存器可写/可读/可恢复。

## 1. 实机可逆读写通过（2026-11-11 00:20）

[原始照片副本](../../logs/v77-user-photo.jpg)，[可复现构建回执](../../logs/v77-build-receipt.json)。

```text

BB flags     0x3b7f
BB bitsteps  0x2d0
BB frames    0x11
RW before    0x0
RW wanted    0xa55a5aa5
RW read      0xa55a5aa5

```

测试地址为厂商 `ili_ic_dummy_check()` 使用的 WDT9_DUMMY2=0x51024，不是AP代码或flash。先三次读取PID，只有身份匹配才写。测试值读回相同后恢复原值并再次读回；0x800/0x1000/0x200位分别证明测试读回、原值恢复、GPIO恢复检查通过。实际17帧、720个完成采样步，与软件契约一致。

同时补显式屏障，保证IES SET→读回、DIR/DOUT预装→mode切换、mode恢复→潜在DIR/DOUT恢复的组间顺序。没有改引脚、SPI mode、半周期10us或1ms帧间隔。MWR与更快时序留待独立实验，不混入这次读写验证。

[v77 镜像](../../images/k9x-ios-v77-RW-BIG.img) SHA256：`5b118679aa2e9cd6468ac1b76852f8c0227822be1b2405375095e3b7c5b52820`。输入基线、XNU、Android回链均保留，仍 touchscreen=0。

## 2. 固件来自本机当前 Android

只读取 `/odm/firmware/tp/210A0/FW_NF_ILI7807S_TIANMA.img`，保存于工作区[设备证据目录](../../assets/device/touch/FW_NF_ILI7807S_TIANMA.img)，未修改手机文件，固件未加入公开Git仓库。

- 文件358,969字节；SHA256=`d6a38c0382ec3f570d6cb282e11ec4ee075000482f3b653334770851518f0e77`。
- 是Oplus FwUp v1包装，不是直接ILI二进制，也不是从第0字节开始的HEX。
- 80字节头 + 358,761字节ASCII Intel HEX + 128字节签名尾。
- HEX payload SHA256=`4c43b5b59a22a2d93af9469f42573a0cdada92c5ce657b6065bfbfbb9c6e0f92`。
- 7,977条记录；记录校验和与4个块CRC均通过。没有宣称验证RSA签名。

[严格解析器](../scripts/parse_ilitek_firmware.py) 和[完整元数据](../../assets/device/touch/firmware-manifest.json)。

| 块 | HEX源起点 | 字节数 | IRAM目标起点 | CRC32/MPEG-2 | 正常运行加载 |
|---|---|---:|---|---|---|
| AP | 0x00000 | 81920 | 0x00000 | 0xbb7b8d39 | 是 |
| DATA | 0x1d000 | 8192 | 0x20870 | 0x061ef7ef | 是 |
| TUNING | 0x1f000 | 512 | 0x20670 | 0x7532981c | 是 |
| MP | 0x14000 | 36864 | 测试模式另定 | 0xb4536eea | 否 |

解码镜像127,488字节，但正常运行只加载90,624字节。DATA/TUNING目标来自B0记录，不使用默认0x20610推断，也不把127,488字节平铺到IRAM 0。

## 3. 源码依据与完整加载的验收条件

固定厂商commit `654f1cb8a1516d446e19832e4da2aad314630469`。

- [SPI hostdl顺序](https://github.com/oppo-source/android_kernel_oppo_mt6833/blob/654f1cb8a1516d446e19832e4da2aad314630469/drivers/input/touchscreen/ILITEK9882/ilitek_v3_hostdl.c#L342-L424)：ICE MCU-OFF、块写入/校验、0x40040写0xAE code reset、退出ICE、等待固件。
- [AF/B0与运行块映射](https://github.com/oppo-source/android_kernel_oppo_mt6833/blob/654f1cb8a1516d446e19832e4da2aad314630469/drivers/input/touchscreen/ILITEK9882/ilitek_v3_hostdl.c#L450-L505)：正常模式只AP/DATA/TUNING。
- [dummy检查](https://github.com/oppo-source/android_kernel_oppo_mt6833/blob/654f1cb8a1516d446e19832e4da2aad314630469/drivers/input/touchscreen/ILITEK9882/ilitek_v3_ic.c#L1089-L1114)：0x51024写A55A5AA5后读回。
- [活体TP信息查询](https://github.com/oppo-source/android_kernel_oppo_mt6833/blob/654f1cb8a1516d446e19832e4da2aad314630469/drivers/input/touchscreen/ILITEK9882/ilitek_v3_ic.c#L934-L988)：F6 20预命令后查询20；这不是“core version”命令，成功条件应来自真实SPI读，而不是 `info_from_hex` 的缓存字段。

下一阶段加载必须：三次PID与dummy读写恢复门控；只写上述3个已校验目标；全局时限；逐块完整读回或独立硬件CRC；失败不启动未验证代码；成功后code reset/退出ICE，做活体命令握手；GPIO恢复。固件加载成功之后，还需真实报告抓包、checksum/72字节像素格式确认及XNU HID接入。
